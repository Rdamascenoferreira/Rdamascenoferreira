## App de Reembolso para Inspetores (ideia/proposta)

### Objetivo
Criar um aplicativo mobile onde inspetores possam registrar despesas de deslocamento e reembolso com comprovação, enquanto um administrador aprova ou recusa cada solicitação.

### Funcionalidades principais
- **Cadastro/Login** com e-mail, telefone (SMS) ou conta Google.
- **Upload de comprovantes** (foto/PDF) com descrição, valor e data.
- **Integração com Google Maps** para calcular a distância (km) entre a casa do inspetor e a residência visitada.
- **Fluxo de aprovação** para o administrador aprovar ou recusar comprovantes.

### Perfis de acesso
- **Inspetor**
  - Cria conta e autentica.
  - Envia comprovantes de reembolso.
  - Informa destino e calcula km percorrido via Maps.
  - Acompanha o status (aprovado/recusado/pendente).
- **Administrador**
  - Visualiza lista de solicitações.
  - Analisa comprovantes.
  - Aprova ou recusa com observação.

### Integrações sugeridas
- **Google Sign-In** para autenticação.
- **Google Maps API** para rotas e cálculo de distância.
